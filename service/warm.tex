% Compiled once during the image build, for its side effect.
%
% Tectonic ships as a single binary and downloads the TeX files a document
% actually asks for on first use, caching them. In a container that cache is
% empty on every cold start unless it is baked in — so the first real compile
% after each deploy would try to pull the bundle, and either take a minute or
% time out. Building this at image-build time fills the cache, and it ships
% inside the image.
%
% KEEP THE PREAMBLE BELOW IN STEP WITH preambleFor() IN src/lib/resumeLatex.ts.
% Drift is not fatal — a package this misses is fetched at runtime the first
% time a real document wants it, costing one slow compile — but every package
% listed here is one the deployed app never waits for.
